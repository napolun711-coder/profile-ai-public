# 本地知识库助手

一个面向个人与小型团队的本地资料知识库应用：上传文档、经过解析与质量门、确认后构建检索索引，并通过聊天获得带来源的回答。

项目使用 **FastAPI + LightRAG + SQLite**。默认只监听本机；局域网访问需要显式开启并在电脑端确认设备。

## 能力

- PDF / Word / Excel / Markdown / 文本 / 图片资料导入
- 本地解析、质量校验、人工确认后入库
- LightRAG 检索、流式回答、引用来源与知识图谱
- SQLite 会话持久化、长期记忆、历史检索
- OCR 插件接口；默认关闭，可选择本机或云端提供方
- 局域网设备配对、手机/平板访问
- 数据备份与恢复
- Edge / 浏览器自带朗读，不下载语音模型

## 环境要求

- Windows 10/11
- Python 3.14（当前快照沿用）
- [uv](https://docs.astral.sh/uv/)
- LightRAG 1.5.6 或兼容版本
- Ollama（若使用 `bge-m3` 本机嵌入）
- 可选 Qdrant

## 本地运行

```powershell
Copy-Item .env.example .env
uv sync
.venv\Scripts\python.exe scripts\start.py
```

浏览器打开：

```text
http://127.0.0.1:8100/web
```

也可以运行 `install_env.bat` 准备依赖，之后使用 `appctl.vbs` 启动。

LightRAG 默认目录为项目下的 `lightrag/`。安装方法将在下一阶段改为一键自动下载。

## 推荐浏览器

**Microsoft Edge 是推荐浏览器**，中文朗读体验最好。其他 Chromium 浏览器仍可正常聊天，但可用系统音色取决于设备和操作系统。

朗读通过浏览器自带的 `speechSynthesis` 完成，本应用不下发语音合成请求，也不附带语音模型。

### 安装为桌面应用

Edge 桌面端：

1. 打开应用页面。
2. 点击右上角 `…`。
3. 选择“应用” → “将此站点安装为应用”。
4. 以后从桌面图标直接进入。

手机 / 平板 Edge：

1. 打开局域网地址。
2. 点击底部或右上角菜单。
3. 选择“添加到手机”或“添加到主屏幕”。

## 手机 / 平板访问

1. 在电脑设置页确认已开启局域网访问。
2. 手机和电脑连接同一 Wi-Fi。
3. 在电脑上运行一次 `allow_lan.bat`，放行应用端口。
4. 手机访问 `http://电脑局域网IP:8100/web`。
5. 首次访问时在电脑设置页确认设备。

不要在路由器上做公网端口映射。局域网访问仅建议在可信网络中使用。

## 语音输入

推荐使用豆包输入法（若设备支持）。它可以在输入法内完成语音识别并直接发送，操作次数通常少于“浏览器录音 → 识别 → 再点页面发送”的流程。

不使用豆包输入法时，可继续使用系统输入法或浏览器自带语音输入。

## 配置

- `.env.example`：部署级最小配置模板
- `config/user-settings.example.json`：设置页配置结构示例
- 密钥只保存在本机，不写入仓库
- 设置页保存后通常需要按提示重启服务

## 隐私

- 默认仅监听 `127.0.0.1`
- 默认不使用云端 OCR
- 默认不扫描文件夹
- 所有资料默认留在本机
- 只有用户配置的模型服务或 OCR 服务会收到相应文本或文件

更多说明见 [隐私与数据](docs/隐私与数据.md)。
