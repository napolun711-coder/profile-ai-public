# 隐私与数据

## 默认边界

- 应用默认仅监听 `127.0.0.1`
- OCR 默认关闭
- 文件夹轮询默认关闭
- 不使用服务端 TTS，不下载语音模型
- 只有用户主动配置的模型、嵌入或 OCR 服务会收到数据

## 数据目录

默认根目录：`%LOCALAPPDATA%\ProfileAI`

| 目录 | 内容 |
|---|---|
| `config` | 用户设置、运行端口 |
| `data` | 上传、解析、数据库、收件箱、原件 |
| `knowledge` | 通过质量门后的 Markdown |
| `rag_storage` | LightRAG 索引 |
| `backend\lightrag` | LightRAG 程序与官方 `.env` |
| `logs` | 应用与服务日志 |
| `output` | 导出文件 |
| `backups` | 本机备份 |

源码目录只保存程序与模板。`PROFILE_AI_HOME` 可覆盖默认根目录。

## 密钥

API Key、OCR Token 和设备授权数据只保存在用户数据目录。不要公开分享：

- `config\user-settings.json`
- `config\runtime.json`
- `backend\lightrag\.env`
- `data\`
- `logs\`
- `backups\`

## 局域网

启用 `APP_HOST=0.0.0.0` 后，同网段设备可以访问应用入口。新设备必须在电脑端确认授权。

不要在路由器上做公网端口映射。

## 云端服务

配置云端 LLM、Embedding、Rerank 或 OCR 后，相应文本、查询或文件会发送到该服务商。请先阅读其隐私条款。
