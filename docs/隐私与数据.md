# 隐私与数据

## 默认边界

- 应用默认仅监听 `127.0.0.1`。
- 默认不使用云端 OCR。
- 默认不扫描任何文件夹。
- 默认不使用服务端 TTS，也不下载语音模型。
- 只有用户主动配置的模型、嵌入或 OCR 服务会收到对应数据。

## 本机数据

运行数据写入项目的 `data/`、`logs/`、`knowledge/`、`output/`、`rag_storage/` 和 `models/` 等目录。上述目录均已加入 `.gitignore`。

其中可能包含：

- 上传原件
- 解析正文
- 会话与记忆 SQLite 数据库
- 设备授权信息
- 检索索引
- 日志和导出文件

## 不要提交

- `.env`
- `config/user-settings.json`
- `data/`
- `logs/`
- `knowledge/`
- `output/`
- `rag_storage/`
- `models/`
- 任何 API Key、Token、设备 Cookie 或证书私钥

## 局域网

开启 `APP_HOST=0.0.0.0` 后，同网段设备可以访问应用入口。应用提供设备配对：

- 新设备首次访问需要在电脑端确认。
- 设备令牌保存在 HttpOnly Cookie 中。
- 服务端只保存令牌哈希。
- 可在设置页删除已授权设备。

## 云端服务

如果配置云端 LLM、Embedding、Rerank 或 OCR：

- 相应文本、查询或文件会发送给该服务商。
- 请阅读服务商的隐私条款。
- 不在使用时及时清空密钥。

## 删除与备份

- 知识库删除与原件删除是分开的范围。
- 原件默认不随知识库记录删除。
- 备份可能包含敏感数据，必须妥善保管，不要上传公共网盘。
