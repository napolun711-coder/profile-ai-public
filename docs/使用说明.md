# 使用说明

## 1. 安装

双击项目根目录的 `setup.cmd`。

首次安装需要联网，安装器会准备：

- uv 与应用依赖（uv 不依赖 PATH，安装后可直接被安装器识别）
- LightRAG 1.5.6
- LightRAG 官方默认 `.env`
- Ollama 与 `bge-m3` 嵌入模型
- 桌面和开始菜单快捷方式

再次运行 `setup.cmd` 可修复缺失组件。

## 2. 首次设置

打开设置页，填写生成模型：

- 提供方：例如 `openai`、`ollama`、`azure_openai`、`gemini`
- 模型名称
- 接口地址
- API Key

嵌入模型默认使用本机 Ollama `bge-m3:latest`。也可以改成任意 LightRAG 支持的远程 Embedding。

分块与召回参数位于“向量存储”卡片下方。

保存后按页面提示重启应用。

## 3. 启动与停止

- 启动：桌面“本地知识库助手”或 `appctl.vbs`
- 停止：桌面“停止本地知识库助手”或 `appctl.bat stop`
- 查看状态：`appctl.bat status`

启动器会自动处理 LightRAG 端口冲突。

首次启动可能需要 1–3 分钟，期间进度停在 92% 表示正在等待网页存活探针，
不是应用卡在 92% 的工作进度。默认最长等待 180 秒；可在 `.env` 中修改
`APP_READY_TIMEOUT`。

如果启动失败，启动器会生成：

```text
%LOCALAPPDATA%\ProfileAI\logs\startup-diagnostic.txt
```

请先不要反复重装，直接把该文件发给维护者。它包含进程退出码、端口监听状态和
相关日志末尾，足以区分杀毒扫描慢、端口占用和应用崩溃。

## 4. 导入资料

1. 点击“上传资料”
2. 选择 PDF、Word、Excel、Markdown、文本或图片
3. 等待本地解析与质量校验
4. 确认“入库”或“跳过”

扫描件需要 OCR。OCR 默认关闭，不会把文件发送到外部。

## 5. 朗读

推荐 Microsoft Edge。

- 阅读回答时点击“朗读”
- 使用浏览器自带语音合成
- 不需要下载语音模型
- 可用音色取决于系统已安装的中文语音

Edge 右上角 `…` → “应用” → “将此站点安装为应用”。

手机/平板 Edge：菜单 → “添加到手机”或“添加到主屏幕”。

## 6. 中文语音输入

推荐豆包输入法（若设备支持）：

1. 长按空格开始语音输入
2. 输入完成后直接点击输入法旁的发送

无需再切回页面点击发送。

## 7. 手机 / 平板访问

1. 电脑和移动设备连接同一局域网
2. 运行 `allow_lan.bat`
3. 将 `APP_HOST` 设为 `0.0.0.0` 并重启
4. 在设置页复制局域网地址
5. 设备打开 `http://电脑IP:8100/web`
6. 在电脑设置页确认设备

仅建议在可信 Wi-Fi 中使用，不要做公网端口映射。

## 8. 数据与备份

用户数据默认位于 `%LOCALAPPDATA%\ProfileAI`。

```powershell
appctl.vbs backup
```

备份位于 `%LOCALAPPDATA%\ProfileAI\backups`。恢复前必须停止应用。
