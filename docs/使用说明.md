# 使用说明

## 1. 启动

首次使用：

```powershell
Copy-Item .env.example .env
uv sync
.venv\Scripts\python.exe scripts\start.py
```

日常可双击 `appctl.vbs` 或运行 `appctl.bat`。

默认地址：`http://127.0.0.1:8100/web`

## 2. 导入资料

1. 点击“上传资料”。
2. 选择 PDF、Word、Excel、Markdown、文本或图片。
3. 等待本地解析与质量校验。
4. 在卡片上确认“入库”或“跳过”。

扫描件需要 OCR。OCR 默认关闭，不会向外部发送文件。

## 3. 提问与引用

- 回答优先使用知识库资料。
- 文末引用可打开本机原件。
- 资料不足时，助手应明确说明，而不是编造。
- 历史检索与长期记忆可在侧栏查看和管理。

## 4. 朗读

推荐使用 **Microsoft Edge**。

- 阅读回答时点击“朗读”。
- 语音由 Edge / 浏览器自带语音合成提供。
- 不下载语音模型。
- 可用音色取决于操作系统已安装的中文语音。
- 其他浏览器可以使用，但体验可能不同。

### 保存为桌面应用

Edge 右上角 `…` → “应用” → “将此站点安装为应用”。

### 手机 / 平板添加到主屏幕

Edge 菜单 → “添加到手机”或“添加到主屏幕”。

## 5. 手机 / 平板访问

1. 电脑和移动设备连接同一局域网。
2. 运行 `allow_lan.bat`，按提示允许防火墙规则。
3. 在 `.env` 中把 `APP_HOST` 改为 `0.0.0.0`，重启应用。
4. 打开设置页，查看并复制局域网地址。
5. 在移动设备打开 `http://电脑IP:8100/web`。
6. 在电脑设置页确认新设备。

安全提示：

- 仅使用可信 Wi-Fi。
- 不要做公网端口映射。
- 不需要手机访问时，把 `APP_HOST` 改回 `127.0.0.1`。

## 6. 中文语音输入

推荐豆包输入法（若设备支持）：

1. 长按空格开始语音输入。
2. 输入完成后直接点击输入法旁的发送。

这样可以少一次页面内发送操作。其他输入法的流程取决于设备实现。

## 7. 备份与恢复

```powershell
appctl.vbs backup
```

恢复前需要停止服务。详细命令见 `scripts/m6_restore.py` 的帮助输出。

## 8. 设置

设置页包含生成模型、嵌入模型、检索、质量门、OCR、记忆和局域网访问。

当前快照仍保留部分历史配置项；下一阶段将收敛为更简洁的统一设置页。
